Collection of 8 ML practice notebooks from the Machine Learning course at ICAI (Ingeniería Matemática e IA, 2025/2026). Each practice covers a different algorithm or technique, from data preparation to ensemble methods.

---

## 📂 Practices

| # | Topic | Key concepts |
|---|-------|-------------|
| P1 | Data Preparation | Cleaning, normalization, train/test split |
| P2 | KNN | K-Nearest Neighbors, distance metrics, hyperparameter tuning |
| P3 | Linear Regression | OLS, feature selection, residual analysis |
| P4 | Linear Regression II | Regularization, Lasso, Ridge, ElasticNet |
| P5 | Logistic Regression | Binary classification, ROC curve, threshold tuning |
| P6 | Cross Validation | K-Fold, GridSearchCV, model selection |
| P7 | LDA | Linear Discriminant Analysis, dimensionality reduction |
| P8 | Decision Tree | Tree pruning, feature importance, overfitting |

---

## 🛠️ Stack

- **Python** — NumPy, Pandas, Matplotlib, Seaborn
- **Scikit-learn** — models, preprocessing, evaluation
- **Jupyter Notebooks** — one notebook per practice

---

## 🚀 How to run

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
jupyter notebook
```

Then open the notebook for the practice you want to explore.
